## Week 1 - History
- One writing system can be used by many languages.
- Cuneiform was an early writing system that looks weird.

## Week 2 - Bits and Bytes
- Data is stored as bits and bytes.
- A byte consists of 8 bits.

## Week 3 - Structure of Text
- Lines are the most fundamental structural element in text files.
- Markup languages embed formatting instructions inside plain text.

## Week 4 - Manipulating Text 
- Text editors handle raw plain text which is essential for writing clean code.
- VS Code is currently the most popular development editor due to its extensions.

## Week 5 - Command Line Interfaces (CLI)
- A CLI lets you control a computer by typing text commands.
- SSH is a secure way to connect to a remote computer over a network.
